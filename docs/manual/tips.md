# Tips

- Super+O shows every workspace and window at once. Click a window to jump to it.
- Hold Super and drag a window with the left mouse button to move it, or with the right button to resize it.
- Super+Minus and Super+Equal make the current column narrower or wider by 10%.
- Super+[ stacks a window into the column on its left. Super+Shift+O then turns that column into tabs.
- Super+F makes a column as wide as the screen. Press it again to go back.
- Screenshots land in ~/Pictures/Screenshots and on the clipboard at the same time.
- Super+T brings back anything you copied earlier.
- A virtual machine or remote desktop needs the Super key for itself: press Super+Escape to hand it over, and again to take it back.
- `nix run nixpkgs#name` runs a program once without installing it.
- `nix shell nixpkgs#name` opens a shell where that program is available until you close it.
- search.nixos.org lists every package and every system setting.
- niri applies its config the moment you save it, so you can tune shortcuts and gaps live.
- Your own settings live in ~/.config. Delete a file there to get the KunstOS default back.
- If an update breaks something, pick an older generation in the boot menu.
- `kunst-apps` removes apps too: unpick them and press Enter.
