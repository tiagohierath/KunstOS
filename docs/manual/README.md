# KunstOS manual

KunstOS is NixOS set up for making art: drawing, painting, 3D, pixel art,
sound and code. It assumes you like to open a terminal, read a config file and
change it. If you come from Windows, start with the first two chapters.

The printable manual is [pdf/manual.typ](pdf/manual.typ), installed on every KunstOS at /etc/kunstos/manual.pdf ("KunstOS Manual" in the apps menu). Start there.
