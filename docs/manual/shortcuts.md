# Shortcuts

**Super** is the key with the Windows logo on it.

## How windows are laid out

Windows sit side by side in columns, on a strip that scrolls sideways. New
windows open to the right of the one you're in. Each workspace is one strip,
and workspaces are stacked on top of each other, so you move left and right
between windows and up and down between workspaces.

## Apps and windows

| Keys | What it does |
|---|---|
| Super+Enter | Opens a terminal |
| Super+R | Opens the apps menu. Type to search, Enter starts the app |
| Super+Q | Closes the window |
| Super+E | Opens the file manager (yazi, in a terminal) |
| Super+Y | Opens Firefox |
| Super+V | Lifts the window out of its column so it floats above the others, or puts it back |
| Alt+Tab | Switches to a window you used recently |

## Moving around

| Keys | What it does |
|---|---|
| Super+H or Super+J | Goes to the column on the left |
| Super+L or Super+K | Goes to the column on the right |
| Super+Shift+J | Goes to the window below, in the same column |
| Super+Shift+K | Goes to the window above, in the same column |
| Super+U | Goes to the workspace below |
| Super+I | Goes to the workspace above |
| Super+O | Shows every workspace and window at once. Click one to go there |

On a touchpad, swipe with three fingers: sideways to scroll through windows,
up or down to change workspace.

## Moving windows

| Keys | What it does |
|---|---|
| Super+Ctrl+H | Moves the column to the left |
| Super+Ctrl+L | Moves the column to the right |
| Super+Ctrl+J | Moves the window down inside its column |
| Super+Ctrl+K | Moves the window up inside its column |
| Super+Ctrl+U | Moves the column to the workspace below |
| Super+Ctrl+I | Moves the column to the workspace above |
| Super+[ | Puts the window into the column on its left, or takes it out of its column to the left |
| Super+] | Same, to the right |
| Super + drag with the left mouse button | Moves a window |
| Super + drag with the right mouse button | Resizes a window |

## Window size

| Keys | What it does |
|---|---|
| Super+Minus | Makes the column 10% narrower |
| Super+Equal | Makes the column 10% wider |
| Super+F | Makes the column as wide as the screen, or back |
| Super+Shift+F | Fullscreen, or back |
| Super+Shift+O | Shows the windows of a column as tabs, or back |

## Screenshots and clipboard

| Keys | What it does |
|---|---|
| Super+Print | Takes a screenshot. Drag to pick an area, then press Space or Enter. It goes to ~/Pictures/Screenshots and to the clipboard |
| Super+T | Opens the clipboard history, so you can paste something you copied earlier |

## Sound, screen and music

The volume, mute, microphone, brightness and play/pause keys on your keyboard
work as printed on them.

## Session

| Keys | What it does |
|---|---|
| Super+Alt+L | Locks the screen. It also locks by itself after 10 minutes, and before the computer sleeps |
| Super+Shift+E | Logs out. It asks first |
| Super+Escape | Lets the app in front receive the Super key, for virtual machines and remote desktops. Press it again to get your shortcuts back |
